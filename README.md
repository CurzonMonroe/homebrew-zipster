# Zipster Homebrew tap

```sh
brew tap CurzonMonroe/zipster
brew install --cask zipster
```

Official Apple Silicon and Intel macOS builds. See [Zipster](https://github.com/CurzonMonroe/Zipster) for requirements, manual downloads, and support.

Stable release CI verifies the public archives and then updates `Casks/zipster.rb` with the version and architecture-specific checksums.
